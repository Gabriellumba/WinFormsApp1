 Cybersecurity Chat Bot

The Cybersecurity Chat Bot is a desktop application developed using C#, .NET, and Windows Forms in Visual Studio. Its purpose is to provide users with basic cybersecurity information through an interactive chat interface. The application allows users to communicate with the chatbot and learn about online privacy, password security, phishing attacks, and online scams.

The chatbot includes features such as personalized greetings, random responses, greeting audio, a custom logo, a typing indicator, and a clear button to reset the conversation. It uses predefined keywords and responses to answer user messages and can remember the user's name during the session.

To run the application, users need Visual Studio with the appropriate .NET development tools and the required image and audio files. The project demonstrates how C# can be used to create a simple graphical chatbot. However, it has limitations because it cannot understand every question, does not use an external AI service, and does not permanently save conversation history. Overall, the project provides a foundation for learning about chatbot development and promoting cybersecurity awareness.
